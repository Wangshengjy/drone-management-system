# 无人机企业智能管理系统（飞手与协作单位）

面向无人机企业的 **智能管理系统**：结合 **多目标加权自动预审**（可配置权重与阈值，对应智能优化中的目标加权与约束筛选思路）与 **Web 前后端分离** 技术，实现飞手与协作单位（含企业、志愿者机构等）的 **线上报名、资料维护、自动预审与人工复核**，以及 **面向公众的备案查询与数据报表**。

## 主要功能

1. **飞手信息管理**：飞手基础信息的添加、修改、删除（管理员）；飞手自助维护备案信息与资质证书；提交后触发自动预审与状态流转（含人工复核、冻结等）。
2. **协作单位管理**：线上报名通道；企业 / 志愿者机构 / 其他类型单位资料维护；审核筛选与增删改（按角色权限）。
3. **自动预审与人工复核**：基于规则与加权综合分的自动预审，结合管理端人工复核队列，提高筛选效率。
4. **公众查询与统计**：公开查询已通过的注册飞手与协作单位（脱敏）；首页统计看板与图表。
5. **用户权限**：**管理员**（全功能）、**协作单位**（本单位注册资料与查询）、**飞手**（本人注册资料与查询）、**访客**（登录后仍仅可使用公开查询与统计，无业务工作台）。

技术栈：后端 Spring Boot 3、MyBatis-Plus、JWT；前端 Vue 3、Vite、Element Plus、ECharts。数据库脚本见 `backend/src/main/resources/db/schema.sql`。
