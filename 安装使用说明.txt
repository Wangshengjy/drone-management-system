========================================
  无人机飞手及协作单位管理系统
  安装使用说明
========================================

一、运行环境要求
----------------------------------------
环境          版本要求      说明
JDK           17+          Spring Boot 3.2 最低要求
Node.js       18+          Vite 5 最低要求
MySQL         8.0+         使用InnoDB引擎
Maven         3.8+         后端构建工具
npm           9+           前端包管理器
操作系统       Windows 10/11 本项目开发环境


二、安装配置说明
----------------------------------------

步骤1：安装MySQL并创建数据库

  打开MySQL命令行或图形工具，执行：

  CREATE DATABASE IF NOT EXISTS emergency_db
    DEFAULT CHARACTER SET utf8mb4
    DEFAULT COLLATE utf8mb4_general_ci;

  数据库连接信息（配置文件：backend/src/main/resources/application.yml）：

  URL：    jdbc:mysql://localhost:3306/emergency_db
  用户名：  root
  密码：    123456


步骤2：启动后端

  cd c:\wurenji\backend
  mvn spring-boot:run

  后端启动时会自动执行DataInitializer：
  1. 检测数据库表是否存在，若不存在自动执行schema.sql建表
  2. 自动创建管理员账号和演示数据
  3. 后端服务运行在 http://localhost:8080


步骤3：启动前端

  cd c:\wurenji\frontend
  npm install        （首次运行需安装依赖）
  npm run dev        （启动开发服务器）

  前端服务运行在 http://localhost:5173
  API请求通过vite.config.ts代理转发到后端8080端口

四、数据库文件说明
----------------------------------------
数据库文件位于 database 文件夹中：

  schema.sql              14张表的DDL建表脚本
  seed.sql                18个飞手+18个单位演示数据
  seed_extra.sql          2个飞手+2个单位追加数据（幂等）
  create-mission-tables.sql  任务相关5张表DDL
  demo-queries.sql        演示查询语句

注意：正常启动后端时不需要手动执行SQL脚本，DataInitializer会自动完成
建表和数据初始化。如需手动初始化，按顺序执行：
  schema.sql -> seed.sql -> seed_extra.sql


五、快速验证流程
----------------------------------------
1. 浏览器打开 http://localhost:5173
2. 点击"进入公开首页"，未登录状态下无法查看飞手/单位信息
3. 点击"登录系统"，选择"管理员"标签，输入 admin / 123456
4. 登录后进入管理后台，可查看飞手审核、单位审核、任务管理、统计看板
5. 退出后用飞手账号 pilot_sample_alpha / 123456 登录，体验飞手工作台
6. 退出后用单位账号 org_sample_horizon / 123456 登录，体验协作单位工作台
