# 用户手册

本系统面向无人机企业与协作场景，支持 **管理员、协作单位、飞手、访客** 等角色；访客可不登录直接浏览公开数据，也可注册 **访客账号** 以便收藏登录态（仍仅能使用公开查询与统计，无业务工作台）。

## 系统能力概览

1. **飞手信息管理**：飞手基础信息的添加、修改、删除（管理员）；飞手本人维护备案信息与资质证书；提交审核后经过自动预审与人工复核，支持状态变更与冻结。
2. **协作单位管理**：线上报名；对企业、志愿者机构等单位进行资料维护与审核筛选；信息增删改按权限控制。
3. **自动预审与人工复核**：系统按可配置规则与加权综合分进行自动预审，并进入人工复核队列，便于高效筛选申请者。
4. **公众查询与报表**：查询已合作/已备案的协作单位与注册飞手（公开接口），首页提供统计看板与图表。
5. **权限分级**：管理员全功能；协作单位管理本单位资料与公开查询；飞手管理本人资料与公开查询；访客仅浏览公开信息（不可进入管理/飞手/单位工作台）。

## 访客（无需登录）

1. 打开前端首页（开发环境一般为 `http://localhost:5173`）
2. 在「公开查询」页签中按关键词、地区或单位类型筛选 **已通过审核** 的飞手与单位（列表为脱敏展示）
3. 右侧「统计看板」展示注册趋势、单位类型分布等聚合信息（只读）

## 注册与登录

1. 点击 **线上报名**，选择角色为 **飞手**、**协作单位** 或 **访客（仅公开查询）**。飞手/单位需填写姓名或单位名称、用户名与密码；访客昵称可选
2. 注册成功后会自动登录；也可在 **登录** 页使用已有账号登录
3. 管理员账号由系统初始化（默认用户名 `admin`，首次启动写入数据库；密码见服务器配置 `app.bootstrap.admin-password`，默认 `123456`）。**请在演示或生产环境中修改默认密码**
4. 如未手动导入 `seed.sql`，系统会自动补充演示账号，便于快速联调：飞手 `pilot_sample_alpha / 123456`、协作单位 `org_sample_horizon / 123456`

## 访客（已登录）

1. 登录后首页显示 **访客仅可浏览公开信息**，**不显示** 飞手/单位/管理工作台入口
2. 使用方式与未登录访客相同：公开查询与统计看板；无法调用需飞手/单位/管理员权限的 API

## 飞手

1. 登录后从首页进入 **飞手工作台**，或访问 `/pilot`
2. 在「我的资料」中维护姓名、手机、备案号、地区等信息，点击 **保存**
3. 在「资质证书」区域填写证书类型、编号、有效期；可使用 **上传文件** 将材料传到服务器，系统自动填入附件 URL
4. 资料填写完整后点击 **提交审核**：系统将执行 **自动预审**（规则 + 加权分），通过后进入 **待人工复核** 队列（硬性不通过将直接 **驳回**）
5. 可在首页查看本人自动预审分数与说明（展示字段以后台记录为准）

## 协作单位

1. 登录后进入 **协作单位工作台**（`/org`）
2. 维护单位名称、类型、统一社会信用代码（18 位）、联系人、手机与地址，**保存**
3. **提交审核**：同样经过自动预审与人工复核流程

## 管理员

1. 使用管理员账号登录后进入 **管理后台**（`/admin`）
2. **概览**：查看待审/已通过数量及汇总统计
3. **审核队列**：在「待审飞手」「待审单位」列表中执行 **通过**、**驳回** 或 **冻结**
4. **操作日志**：按时间与实体查看全流程留痕
5. **预审配置**：以 JSON 编辑阈值、黑名单关键词与权重（保存后立即作用于新的自动预审）

## 常见问题

- **无法登录**：检查用户名密码、账号是否被禁用、后端与数据库是否已启动
- **提交审核失败**：确认必填项已填、证书未过期、未命中黑名单关键词（可在预审配置中调整）
- **公开查询无数据**：仅展示 **已通过** 的备案信息，请先完成审核流程
